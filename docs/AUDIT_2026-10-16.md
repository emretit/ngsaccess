## 3. Bulgular

### 🔴 B1 — Hik event kataloğu: başarısız yüz = "izin verildi"
- [convex/lib/hikEventCatalog.ts:41-64](../convex/lib/hikEventCatalog.ts)
- SDK referansı (`tmp/pdfs/hikvision_device_network_sdk.txt:18202-18210`, `docs/sdk/appendix-c/c.1-access-control-event-types.md:266-270`):
  - `76 = 0x4c MINOR_FACE_VERIFY_FAIL` → kodda **GRANTED** setinde.
  - `77 = 0x4d MINOR_EMPLOYEENO_AND_FACE_VERIFY_PASS` → kodda **DENIED** setinde.
  - `0x45/0x48` (çalışan no + parmak izi geçti) vb. pass kodları hiç yok → `inferAccessStatus` undefined → `reddedildi`.
- Etki: canlı yol [convex/cardReadings.ts:886-892](../convex/cardReadings.ts) bu sonucu PDKS kaydına yazar →
  yüz terminalinde başarısız deneme giriş sayılır, geçerli "çalışan no + yüz" girişleri ret sayılır.
- Düzeltme (~1 saat): setleri SDK tablosundan (0x01–0x50 aralığı) yeniden kur + `hikEventCodes.test.ts`'e golden test.

### 🔴 B2 — Yüz/parmak izi Hikvision'a otomatik gitmiyor
- [convex/employeeFaces.ts:98,126](../convex/employeeFaces.ts), [convex/employeeFingerprints.ts:102,151](../convex/employeeFingerprints.ts)
- Scheduler `api.actions.hikvisionSync.syncEmployeeFaceToDevices` vb. **authedAction**'ları çağırıyor.
  Zamanlanmış fonksiyonda kullanıcı kimliği yok → `authedAction` "Giriş yapmanız gerekiyor" ile throw.
  Aynı bug IDE ve kişi/kural sync'inde `*Internal` varyantlarla çözülmüştü; yüz/parmak izi atlanmış.
- Düzeltme (~1 saat): 4 action için `internalAction` varyantı + scheduler çağrılarını `internal.*`'a çevir.

### 🔴 B3 — `/card-reader` token'sız istekle PDKS kaydı yazıyor
- [convex/http.ts:79-97](../convex/http.ts): Bearer yoksa "deprecated" uyarısıyla serial/IP lookup'a düşüyor.
- 5 cihazın 4'ünde `apiToken` yok. Cihaz seri numarasını bilen biri sahte giriş/çıkış kaydı yazabilir (PDKS sahteciliği).
- Not: Hikvision `httpHosts` özel header gönderemez → token URL'de (`/card-reader?t=<token>`) kabul edilmeli.
- Düzeltme (~2 saat): query-token desteği + tüm cihazlara token + token'sız isteği reddet (geçiş tarihi belirle).

### 🟡 B4 — PDKS 3 ekran 3 farklı mesai hesaplıyor (R8)
Tablo = ham dakika, bordro = net + haftalık, detay = net + sabit 8 saat. Bordroya giden rakam ekrana göre değişiyor.
Ürün kararı gerekli: tek kanonik hesap seçilmeli.

- Convex free-plan kotası (geçmişte 980K/1M) — IDE requeue cron'u kota için kapalı.
- IDE MQTT plaintext 1883 (panel CA dosyası yüklenemedi); Wiegand hattı sniff/replay'e açık.

## 4. Hikvision entegrasyon haritası

| Yol | Ne | Durum |
|---|---|---|
| ISAPI httpHosts push → `/card-reader` | Cihaz event'i doğrudan Convex'e POST | Çalışıyor, token zorunlu değil (B3) |
| ISUP 5.0 → Hik Device Gateway (Hetzner) → ISAPI passthrough | NAT arkası cihaz, port açma yok; ~25 op | Kod hazır, **canlı cihaz yok** |
| localBridge (Windows EXE, HCNetSDK port 8000) | DS-K2804 (ISAPI'siz panel) | Installer var, son trafik 2026-06-25 |

Hikvision'ın resmi T&A entegrasyon yolları (TPP) ve bizim seçimimiz:

| Yol | Gereksinim | Bizim için |
|---|---|---|
| ISAPI (doğrudan) | Her terminale statik IP | Sahada zor; gateway passthrough ile kullanıyoruz |
| Push SDK / ISUP | Platformda sabit IP+port, cihaz dışarı bağlanır | **Mevcut yol** — bulut için Hikvision'ın önerdiği |
| Hik-Connect Team OpenAPI | Bulut, lisans, yerel yazılım yok | Alternatif: gateway barındırmayı kaldırır |
| HikCentral Pro OpenAPI | Windows sunucu + lisans | Uygun değil (bulut hedefimizle çelişir) |
| Dosya export (CSV) | Lisans | Geliştirme gerektirmez, ham veri yok |

Açık kaynak ISUP sunucusu bulunamadı → Hik Device Gateway (ücretsiz, resmi) doğru tercih.
Gateway sınırı: 200 ISAPI-passthrough cihaz, yalnız x86_64.

## 5. Web araştırması — işe yarayan bulgular

**GitHub referansları**
- [Shaykhnazar/hikvision-isapi](https://github.com/Shaykhnazar/hikvision-isapi) — PHP/Laravel, MIT, v1.5.4 (2025-11). Kişi/kart/yüz/parmak izi + httpHosts webhook servisi + `hikvision-probe` aracı. Desen kaynağı.
- [uchkunr/hikvision-best-practices](https://github.com/uchkunr/hikvision-best-practices) — ISAPI referans (dikkat: minor kod numaraları SDK ile çelişiyor).
- [Iakovosv/Hikvision_access](https://github.com/Iakovosv/Hikvision_access), [Titosoft/hikvision-access-control](https://github.com/Titosoft/hikvision-access-control), [lokyiec/ha-hikvision-acs](https://github.com/lokyiec/ha-hikvision-acs/pull/1) — Home Assistant yerel ISAPI entegrasyonları (alertStream / AcsEvent polling).
- ZKTeco ADMS (iclock push) sunucuları: [laravel-zkteco-adms-server](https://packagist.org/packages/athwari/laravel-zkteco-adms-server), [zkteco-adms](https://packagist.org/packages/tanemrahman/zkteco-adms).

**Sahadan dersler (kodumuza uygulanabilir)**
1. Firmware'ler arası minor kod farkı var (bir DS-K1T805 kartı `minor=1` raporluyor, yüz `75`'i hiç göndermiyor) → B1 düzeltmesi + capability/event-katalog loglaması şart.
2. ~5 hatalı login → admin hesabı ~30 dk kilit; 401 mesajı yanlış şifre / kilit / yetki eksikliğini ayırmıyor → gateway retry'ında backoff + kilit tespiti.
3. Yüz fotoğrafı: JPEG, ≤200 KB, ≥80×80, tek yüz; kişi önce oluşturulmalı; multipart sırası metadata → resim.
4. ISAPI hesabı "Remote: Parameters Settings" + "Remote: Log Search" yetkisi istiyor — kurulum checklist'ine.
5. CVE-2025-66176 (Hikvision erişim kontrol, LAN'dan keşif paketiyle cihaz arızası, CVSS 8.8) → firmware güncelleme takibi.

**Pazar**
- Hikvision + HR entegrasyonu ticari olarak satılıyor (Frappe "Attendance Sync", ücretli Hikvision bağlayıcıları, TopKey → Hik-Connect Team OpenAPI).
- Türkiye: Kolay İK PDKS donanımsız/mobil, biyometri toplamıyor (KVKK argümanı); Biosoft bordro Hikvision cihazlarıyla
  çalışıyor ama yerel ağ + port açma istiyor. ngsaccess farkı: bulut + port açmadan (ISUP) + çoklu marka (Hik + IDE Smart) + SGK export + mobil check-in.
- Wiegand → OSDP geçiş trendi (Axis 2025, BruCON 2023): Wiegand sniff/replay'e açık.
