## Ürün sözleşmesi ve gerçek kapsam

- Hızlı işlem gerçek kapı komutudur; komut onayı, fiziksel geçiş ve ham hareket ayrı olaylardır. Salt command cardReading yazmaz.
- Mobil çalışan yalnız kendi inactive ön kaydını yönetir; gerçek kart/bölge ve erişim aktivasyonunu yetkili web operatörü yapar. SMS/e-posta gönderilmiş denmez.
- Hareket geçmişi modern İstanbul ham takvim günüdür; resmi vardiya, ücret, süre veya geç kalma motoru değildir.
- E-posta hatırlanır; parola saklanmaz. Token güvenli depodadır; açık logout yerel restore iznini kaldırır. Offline revoke uzak iptal garantisi değildir.
- Android/iOS desteklenir; sistem fontları kullanılır. Sahte push, reset e-postası veya uydurulmuş hukuk URLsi sunulmaz.

### Kısmi capability ve destek sınırları

- Geçmiş facet capability kısmi: yalnız oturumda keşfedilmiş cihazlar. AH-W06nın sonraki sayfa/aynı-ad-ID kabulünü karşılar; baştan exhaustive history facet servisi teslim edilmedi.
- QR device_challenge capability kısmi: v1 parser tanır, ekran unsupported gösterir; güvenilir telefon tüketim/komut endpointi yok. Seçilen ürün generic reader QR + ayrı Home command; nonexistent producer varsayımla eklenmedi.
- IDE/Hik UUID reader token desteği yok; supportsReaderToken false. Generic okuyucu remote unlock sağlamaz. IDE/Hik gateway gerçek command ile reader hareketi ayrı kanallardır.
- Hik localBridge mobil açma kapısı kaynakta unsupported: depodaki Windows roster consumer ile mevcut poll API uyumsuzluğu nedeniyle çalışıyor denmez.
- IDE command için broker kimliği/ACL izolasyonu ve firmware dedup gerçek kabulü gerekir; MOBILE_IDE_ISOLATION_VERIFIED=true operatör attestationı varsayılan kapalı gatein yerine kanıt üretmez.
- Visitor mobil süreç ölümü boyunca create niyeti/draft kalıcılığı yok; aynı provider oturumunda requestId replay vardır. PII diske yazılmaz; relaunch gerçek listeyle uzlaşma ayrıca doğrulanır.
- Push, anonim reset, self-service ad/e-posta, payroll/vardiya/ücret hesapları ve harici telemetry teslim edilen özellikler değildir; ilgili UI sahte başarı vermez.
