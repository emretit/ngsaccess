## Denetim sorularına kısa cevap

Route guard/allowlist değişmedi (`route_paths.dart` diff yok). Kamera: `_reconcileCamera`/`_gate` yolu aynı, direkt `camera.start` eklenmemiş; izin isteği mevcut `_checkPermission(request:true)` üzerinden. Login: autofill/next/done/`_emailEdited`/duplicate-submit/`clearError` aynı; ilk hataya focus eklendi (`:69-77`); hata artık kalıcı `AppDataNotice` (liveRegion). Splash: `onRetry`/`onUseLogin` aynı, testli. Forgot: gerçek clipboard başarı/başarısızlık, sahte "gönderildi" yok. Profil: tema/dil kaydı hatada sheet açık + notice; geri tuşu kilidi var, sürükleme açığı RV2-03.
