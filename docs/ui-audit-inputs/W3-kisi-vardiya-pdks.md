# W3 — Kişiler, vardiya, PDKS ve sayfalar input border audit

Statik tarama: **190 üretim dosyası** (144 TSX; testler hariç), input/arama/tarih bileşeni veya kapsam dışı checkbox/file eşleşmesi içeren **50 dosya**. **28 bulgu: Y=3, O=25, D=0**; kategoriler A=3, D=9, E=16. En sık tekrarlanan sebep, hata bilgisinin `aria-invalid` olarak taşınmasına rağmen kontrolün border rengini değiştiren bir kural bulunmaması; ana ring kırpılması ise FormDialog gövdesinin yatay padding içermemesi.

Salt okuma kaynak incelemesidir; canlı tarayıcı/piksel doğrulaması yapılmadı. A satırları verilen doğrulanmış FormDialog vakasıyla aynı ata zincirini taşır; shared wrapper tasarımı ve B kategorisi W1 kapsamına bırakıldı. Aynı formdaki aynı kök sebebe sahip alanlar tek bulgu olarak sayıldı; kategori D ham element anlamındadır, önem D ile karıştırılmamalı. CSS taramasında `src/**/*.css` içinde `aria-invalid` veya invalid-border eşlemesi bulunmadı; bu nedenle E satırları yalnız ARIA eksikliği iddiası değildir, görünür hata border eksikliğini de kapsar.

## Ortak kök sebepler

- **FormDialog gövdesi (`src/components/shared/FormDialog.tsx:91`)**: `overflow-y-auto` ve yatay padding yok. W3 içinde kesin Input/Textarea tüketicileri: `src/components/departments/AddDepartmentDialog.tsx`, `src/components/departments/CompanyDialog.tsx`, `src/components/pdks/ManualPdksEditDialog.tsx`. Tek wrapper düzeltmesi üç A bulgusunu çözer. `src/components/departments/MoveDepartmentDialog.tsx:25` de aynı wrapperı kullanıyor fakat mevcut kontrol ham native select; primitive ringi olmadığı için mevcut ring kırpılması ayrıca doğrulanmadı ve A sayısına katılmadı.
- **Hata border sözleşmesi**: `Input`/`Textarea`/`SelectTrigger` normal border sınıfını koruyor; FormFieldWrapper hata durumunu ARIA olarak taşıyor, border sınıfı eklemiyor. Ayrıntılı wrapper/primitive çözümü W1 tarafından ele alınmalı. Etkilenen dosyalar: `EmployeeFormFields.tsx`, `BatchCardAssignDialog.tsx`, `ManualPdksEditDialog.tsx`, `AddDepartmentDialog.tsx`, `CompanyDialog.tsx`, `AddShiftDialog.tsx`, `ShiftSelect.tsx` (tüketicileri `AssignmentEditDialog.tsx`, `DepartmentTargetPicker.tsx`), `LeaveForm.tsx`, `Login.tsx`, `Register.tsx`, `VerifyEmail.tsx`, `ReportScreen.tsx`, `AuditFilters.tsx`, `PDKSImportDialog.tsx`. `EmployeeConsentsCard.tsx` ve `BatchCardAssignDialog.tsx` için ayrıca yerel ARIA bağlantısı gerekir; `LeaveFilters.tsx` için hata doğru alana bağlanmalıdır.
- **Dağılan native select stilleri**: `EmployeeFormFields.tsx`, `EmployeeFingerprintCard.tsx`, `BatchCardAssignDialog.tsx`, `MoveDepartmentDialog.tsx`, `LeaveForm.tsx`, `LeaveFilters.tsx`, `AddShiftDialog.tsx`, `PDKSExportColumns.tsx`, `Alarms.tsx`. Tek ortak native select stili veya SelectTrigger kullanımına geçiş, farklı `bg-background`/`bg-surface`, outline/ring ve boyut davranışlarını birleştirir.
