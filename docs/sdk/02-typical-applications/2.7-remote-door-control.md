# Uzaktan Kapı Kontrolü (Remotely Control Door)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.7, s.64–66

## Özet

Erişim kontrolcüsünde kapıyı uzaktan **açma, kapatma, sürekli açık tutma, sürekli kapalı tutma** komutları gönderilebilir. ngsaccess'te admin panel'inden "kapıyı aç" butonu, acil senaryolar (yangın, panik) veya VIP misafir senaryoları için kullanılır.

## Tek API: `NET_DVR_ControlGateway`

```c
BOOL NET_DVR_ControlGateway(LONG lUserID, LONG lGatewayIndex, DWORD dwStaic);
```

| Parametre | Anlam |
|---|---|
| `lUserID` | `NET_DVR_Login_V40`'tan dönen kullanıcı ID |
| `lGatewayIndex` | Access controller'daki kapı no. **1**'den başlar. `-1` = tüm kapılar |
| `dwStaic` | Komut: **0** = Close, **1** = Open, **2** = Remain Open, **3** = Remain Closed |

## Akış
```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_ControlGateway(lUserID, 1, 1)   // kapı 1'i aç
  → NET_DVR_Logout / NET_DVR_Cleanup
```

## Önemli Uyarılar

1. **Multi-factor auth modunda:** Eğer cihaz multi-factor auth kullanıyorsa, bu API sadece `NET_DVR_GROUP_COMBINATION_INFO_V50` struct'ındaki `dwGroupNo` parametresi `0xffffffff` olarak set edildiğinde çalışır.
2. Kontrol öncesi mutlaka `NET_DVR_Init` + `NET_DVR_Login_V40` çağrılmış olmalı.
3. İşlem sonrası `NET_DVR_Logout` + `NET_DVR_Cleanup` ile kaynak serbest bırak.

## Örnek (PDF s.66)

```c
#include <stdio.h>
#include <iostream>
#include <afx.h>
#include "Windows.h"
#include "HCNetSDK.h"

void main() {
    NET_DVR_Init();
    NET_DVR_SetConnectTime(2000, 1);
    NET_DVR_SetReconnect(10000, true);

    LONG lUserID;
    NET_DVR_USER_LOGIN_INFO struLoginInfo = {0};
    struLoginInfo.bUseAsynLogin = 0;
    strcpy(struLoginInfo.sDeviceAddress, "192.168.1.64");
    struLoginInfo.wPort = 8000;
    strcpy(struLoginInfo.sUserName, "admin");
    strcpy(struLoginInfo.sPassword, "abcd1234");

    NET_DVR_DEVICEINFO_V40 struDeviceInfoV40 = {0};
    lUserID = NET_DVR_Login_V40(&struLoginInfo, &struDeviceInfoV40);
    if (lUserID < 0) {
        printf("Login failed, error: %d\n", NET_DVR_GetLastError());
        NET_DVR_Cleanup();
        return;
    }

    // Door 1'i aç
    LONG  lGatewayIndex = 1;
    DWORD dwStaic       = 1;  // 0=Close, 1=Open, 2=Remain Open, 3=Remain Closed
    BOOL  bRet = NET_DVR_ControlGateway(lUserID, lGatewayIndex, dwStaic);
    if (!bRet) {
        printf("NET_DVR_ControlGateway failed, error: %d\n", NET_DVR_GetLastError());
    }

    NET_DVR_Logout(lUserID);
    NET_DVR_Cleanup();
}
```

## ISAPI Karşılığı

HCNetSDK yerine HTTP fetch ile aynı şey:
```http
PUT /ISAPI/AccessControl/RemoteControl/door/1 HTTP/1.1
Authorization: Digest ...
Content-Type: application/xml

<?xml version="1.0" encoding="UTF-8"?>
<RemoteControlDoor>
  <cmd>open</cmd>     <!-- open | close | alwaysOpen | alwaysClose -->
</RemoteControlDoor>
```

veya tüm kapılar için: `PUT /ISAPI/AccessControl/RemoteControl/door/-1`

> **Not:** Bu URI Appendix A katalogunda **explicit listelenmemiş** olsa da yaygın Hikvision firmware'lerinde mevcut. Cihaz `/ISAPI/AccessControl/capabilities` GET ile `<isSupportRemoteControl>` node'unu kontrol etmek iyi pratik.

## ngsaccess Tarafında Notlar

### Kullanım Senaryoları
- **Admin panel "Kapıyı aç" butonu:** UI'dan bir kez tetiklenir, Convex action ISAPI PUT yapar
- **Acil "Tüm kapılar açık":** Yangın senaryosu için → `door/-1` + `cmd: alwaysOpen`
- **VIP misafir geliş:** Geçici olarak kapıyı `alwaysOpen` yap, X dakika sonra `open` ile normale dön
- **Mesai dışı erişim onayı:** Çalışan kart okutamadıysa admin onayı ile manuel açma

### Convex Action Örneği (önerilen)
```typescript
// convex/actions/hikvision/remoteControlDoor.ts (önerilen)
import { action } from "../../_generated/server";
import { v } from "convex/values";

export const openDoor = action({
  args: { deviceId: v.id("devices"), doorNo: v.number() },
  handler: async (ctx, { deviceId, doorNo }) => {
    const device = await ctx.runQuery(/* device lookup */);
    const url = `http://${device.deviceIp}/ISAPI/AccessControl/RemoteControl/door/${doorNo}`;
    const res = await fetch(url, {
      method: "PUT",
      headers: { Authorization: "Digest ..." },  // digest auth helper
      body: `<RemoteControlDoor><cmd>open</cmd></RemoteControlDoor>`,
    });
    // log + return
  },
});
```

### Güvenlik
- Bu action mutlaka **admin-only** olsun (`auth: ["admin"]`)
- Her çağrı audit log'a yazılsın (`auditLogs` tablosu: who, when, doorId, cmd)
- Rate limit: aynı kullanıcı 10s içinde max 3 kez
