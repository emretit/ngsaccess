# Diğer Uygulamalar (Other Applications)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.10, s.79–83

## Özet

Yukarıdaki 9 ana akışın dışında kalan **niş özellikler**: Intelligent Identity Detection Terminal (TC kimlik okuma), video intercom device ID, kart okuyucu parametreleri, NFC ayarları vb.

ngsaccess için bu özellikler **opsiyonel** — TC kimlik okuma ve NFC enable/disable yaygın senaryolar.

---

## Intelligent Identity Detection Terminal

TC kimlik kartlı erişim. Genelde resepsiyon/ziyaretçi kayıt cihazları.

| İşlem | URI | Method | Payload |
|---|---|---|---|
| Capability | `/ISAPI/AccessControl/IdentityTerminal/capabilities` | GET | `XML_Cap_IdentityTerminal` |
| Get params | `/ISAPI/AccessControl/IdentityTerminal` | GET | `XML_IdentityTerminal` |
| Set params | `/ISAPI/AccessControl/IdentityTerminal` | PUT | `XML_IdentityTerminal` |

İlgili struct kullanılmaz — direkt XML payload (PDF s.361).

## Reader (Kart Okuyucu) Parametreleri

Her bir kart okuyucunun (RS485 üzerinden bağlı) ayarları.

| İşlem | API | Command | Struct |
|---|---|---|---|
| Get | `NET_DVR_GetDVRConfig` | `NET_DVR_GET_CARD_READER_CFG_V50` (2505) | `NET_DVR_CARD_READER_CFG_V50` |
| Set | `NET_DVR_SetDVRConfig` | `NET_DVR_SET_CARD_READER_CFG_V50` (2506) | `NET_DVR_CARD_READER_CFG_V50` |

`NET_DVR_CARD_READER_CFG_V50` (PDF s.154) içeriği:
- `byEnable` — okuyucu aktif mi
- `byOkLedPolarity`, `byErrorLedPolarity` — LED kutupları
- `byBuzzerPolarity` — buzzer kutbu
- `byDoorNo` — hangi kapıyla ilişkili
- `bySwipeInterval` — kart okutma intervali
- `dwPressTimeout`, `dwEnableFailAlarm` — alarm parametreleri
- `byMaxReadCardFailNum` — max başarısız okuma sayısı
- `byEnableTamperCheck` — tamper detection

## ngsaccess Tarafında Notlar

### TC Kimlik Senaryosu
Ziyaretçi yönetimi modülü için:
1. Resepsiyon kullanıcısı admin panelinde "Yeni Ziyaretçi" formu açar
2. Cihazda "Kimlik Okut" tetiklenir → `POST /ISAPI/AccessControl/CaptureIDInfo?format=json`
3. Cihaz TC kimlik kartını okur, kimlik bilgileri JSON olarak döner
4. ngsaccess'e `visitors` tablosuna kaydedilir, geçici kart numarası atanır

### NFC Senaryosu
Modern Android telefonları NFC ile cihaza okutarak geçebilir. `NFCCfg.enabled = true` ile aktif et — sonra kart numarası olarak telefon NFC ID kullanılır.

### Kart Okuyucu Parametre Yönetimi
Her cihaz için **default reader configuration** ngsaccess'te tutulmalı:
```typescript
// convex/seedDefaults.ts (önerilen)
const defaultReaderCfg = {
  byEnable: 1,
  byOkLedPolarity: 1,
  byErrorLedPolarity: 1,
  byBuzzerPolarity: 1,
  bySwipeInterval: 1000,   // ms
  dwPressTimeout: 10,       // saniye
  byMaxReadCardFailNum: 5,
  byEnableTamperCheck: 1,
};
```
