# Turnike Ayarları (Turnstile Settings)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.9, s.71–79

## Özet

Turnike (lane management device), ofis/metro/konut girişlerinde kişi geçişini kontrol eden cihaz. Kart, QR kod veya kimlik tarama ile auth gerektirir. Yetkisiz giriş/çıkış alarm tetikler.

**Turnike Tipleri:** Swing barrier, Flap barrier, Tripod turnstile

Hikvision turnikelerinde **2 controller** vardır:
- **Lane Controller (slave):** IR sensörleri ve motor kontrolü
- **Main Controller (master):** Auth, kart okuyucu, üst platform iletişimi

## 2.9.2 Main Controller Ayarları

Main controller upper-level platform (ngsaccess) ile konuşur. Ana fonksiyonlar:

### Upload Audio File (Sesli uyarı)
1. `NET_DVR_GetDeviceAbility` — `<UploadRightControllerAudio>` desteği kontrolü
2. `NET_DVR_UploadFile_V40` — `dwUploadType = UPLOAD_RIGHT_CONTROLLER_AUDIO` (42)
3. `NET_DVR_GetUploadState` — progress takip
4. `NET_DVR_UploadClose` — kapat

> Eğer progress `4` (network disconnected) ise step 2'yi tekrarla.

### Download Audio File
1. `NET_DVR_GetDeviceAbility` — `<DownloadRightControllerAudio>` desteği
2. `NET_DVR_StartDownload` — `dwDownloadType = NET_SDK_DOWNLOAD_RIGHT_CONTROLLER_AUDIO` (24)
3. `NET_DVR_GetDownloadState` — progress
4. `NET_DVR_StopDownload` — durdur

### Audio File Parameters (ISAPI)
| İşlem | URI | Method |
|---|---|---|
| Capability | `/ISAPI/AccessControl/RightControllerAudio/capabilities` | GET |
| Get | `/ISAPI/AccessControl/RightControllerAudio/<ID>` | GET |
| Set | `/ISAPI/AccessControl/RightControllerAudio/<ID>` | PUT |
| Delete | `/ISAPI/AccessControl/RightControllerAudio/<ID>` | DELETE |

İlgili struct: `NET_DVR_RIGHT_CONTROLLER_AUDIO_PARAM` (s.202)

## ngsaccess Tarafında Notlar

### Turnike Senaryosu
ngsaccess'te turnike modelleri için (ör. ofis girişi):
1. Cihazı `devices` tablosuna ekle (`deviceType: "turnstile"`)
2. Status polling action ile `GateStatus`, `GateIRStatus`, `GateRelatedPartsStatus` periyodik kontrol et — bkz. [2.8 Status Monitoring](./2.8-status-monitoring.md)
3. Tailgating/Reverse Passing event'leri için [c.1 Access Control Event Types](../appendix-c/c.1-access-control-event-types.md) → MAJOR_EVENT 0x5, minor `0x85`, `0x86`, `0x87`, `0x88`

### Alarm Output Use Cases
- **Yetkisiz geçiş alarmı:** Tailgating veya Force Access olunca cihazın output relay'ini tetikle → siren/ışık
- **Manuel ihbar:** Admin panelinden "uzaktan alarm tetikle"

### Audio File (Sesli Uyarı)
Turnikeler "Lütfen kart okutun" gibi sesli mesajları upload edilen audio dosyasından çalar. Çoklu dil desteği için her dile bir dosya yükle.
