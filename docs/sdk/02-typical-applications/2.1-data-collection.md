# Veri Toplama (Data Collection)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.1, s.8–16

## Özet

Çalışan/ziyaretçi kayıtları için **TC kimlik, kart, yüz, parmak izi** datalarının cihaz üzerinden toplanması. 3 farklı senaryo:

- **2.1.1 Online Collect Data** — Cihaz ağa bağlı, anlık olarak data toplanıp client'a streamleniyor
- **2.1.2 Offline Collect Data** — Cihaz ağdan bağımsız, kişi listesi USB ile import edilip cihazda lokal olarak toplanıyor, sonra export ediliyor
- **2.1.3 Collect Fingerprint** — Parmak izi recorder cihazından parmak izi okutturma

ngsaccess için **Online Collect** en yaygın senaryo (örn. admin panel'inde "Kart Okut" butonu).

## 2.1.1 Online Collect Data

### Akış (PDF Figure 2-1, s.9)
```
NET_DVR_Init → NET_DVR_Login_V40
  → GET /ISAPI/AccessControl/capabilities                              ← yetenek
  → GET /ISAPI/AccessControl/CaptureRule/capabilities?format=json     [opsiyonel]
  → GET /ISAPI/AccessControl/CaptureRule?format=json                  [opsiyonel]
  → PUT /ISAPI/AccessControl/CaptureRule?format=json                  ← rule set
  → GET /ISAPI/AccessControl/CapturePresetParam/capabilities          [opsiyonel]
  → PUT /ISAPI/AccessControl/CapturePresetParam?format=json           ← preset set
  → Cihazdan veri topla (kart/kimlik/yüz/parmak izi)
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Capability Node'ları
| Yetenek | XML Node | Açıklama |
|---|---|---|
| Online ID card | `<isSupportCaptureIDInfo>` | TC kimlik okuma destekli mi? |
| Online card | `<isSupportCaptureCardInfo>` | Kart okuma destekli mi? |
| Online face | `<CaptureFace>` (AcsAbility) | Yüz toplama destekli mi? |
| Capture preset | `<isSupportCapturePresetParam>` | UI'da gösterilecek ön bilgi (ör. çalışan adı) |
| Capture rule | `<isSupportCaptureRule>` | Veri toplama kuralı set edilebiliyor mu? |

### Spesifik Veri Toplama

#### Collect ID Card Information
1. `GET /ISAPI/AccessControl/capabilities` → `<isSupportCaptureIDInfo>true</...>`
2. `GET /ISAPI/AccessControl/CaptureIDInfo/capabilities?format=json` → `JSON_IdentityInfoCap`
3. `POST /ISAPI/AccessControl/CaptureIDInfo?format=json` + `JSON_IdentityInfoCond`
   - Response: `JSON_IdentityInfo` (TC no, ad, doğum tarihi, fotoğraf base64)

#### Collect Card Information
1. `GET /ISAPI/AccessControl/capabilities` → `<isSupportCaptureCardInfo>true</...>`
2. `GET /ISAPI/AccessControl/CaptureCardInfo/capabilities?format=json` → `JSON_CardInfoCap`
3. `GET /ISAPI/AccessControl/CaptureCardInfo?format=json`
   - Response: `JSON_CardInfo_Collection` (kart no, kart tipi, vb.)

#### Collect Face Data
1. `NET_DVR_GetDeviceAbility (ACS_ABILITY)` → `<CaptureFace>` node
2. `NET_DVR_StartRemoteConfig` + `NET_DVR_CAPTURE_FACE_INFO` (cmd 2510)
   - `NET_DVR_CAPTURE_FACE_COND` (input)
   - `NET_DVR_CAPTURE_FACE_CFG` (output via callback)
3. `NET_DVR_StopRemoteConfig`

#### Collect Fingerprint

## 2.1.2 Offline Collect Data

### Senaryo
Cihaz **ağa bağlı değil** (LAN-only, internet'siz). Önce kişi listesi (kart no + ad) USB ile import edilir; cihaz lokalde data toplar (kart/kimlik/yüz/parmak izi); sonra toplanan data USB ile export edilir.

### Akış (PDF Figure 2-2, s.13)
```
NET_DVR_Init → NET_DVR_Login_V40
  → GET /ISAPI/AccessControl/capabilities                             ← <isSupportOfflineCapture>
  → GET /ISAPI/AccessControl/OfflineCapture/capabilities?format=json  → JSON_OfflineCaptureCap

  // Template indir + doldur + upload
  → NET_DVR_StartDownload (NET_SDK_DOWNLOAD_OFFLINE_CAPTURE_INFO_TEMPLATE = 40)
  → NET_DVR_UploadFile_V40 (UPLOAD_OFFLINE_CAPTURE_INFO = 56)
        Struct: NET_DVR_DOOR_FILE_UPLOAD_PARAM
  → PUT /ISAPI/AccessControl/OfflineCapture/ruleInfo?format=json + JSON_RuleInfo

  // Cihaz offline toplama yapar (kullanıcı parmak basar / kimlik tarar)

  → GET /ISAPI/AccessControl/OfflineCapture/progress?format=json     → JSON_CaptureProgress

  // Toplama bittikten sonra: export / download / search / delete
  → PUT /ISAPI/AccessControl/OfflineCapture/dataOutput?format=json + JSON_DataOutputCfg
  → NET_DVR_StartDownload (NET_SDK_DOWNLOAD_CAPTURE_DATA = 41)
  → NET_DVR_StartRemoteConfig (NET_DVR_CAPTURE_DATA_SEARCH = 2554)
        cond: JSON_SearchTaskCond
        result: NET_DVR_JSON_DATA_CFG
  → DELETE /ISAPI/AccessControl/OfflineCapture/DataCollections/<captureNo>?format=json
  → DELETE /ISAPI/AccessControl/OfflineCapture/DataCollections?format=json  ← tümünü sil

  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Upload Failed Details
Import sırasında başarısız olan kişileri görmek için:
```
GET /ISAPI/AccessControl/OfflineCapture/uploadFailedDetails?format=json
→ JSON_UploadFailedDetails
```

## 2.1.3 Collect Fingerprint

### Senaryo
Cihazın **parmak izi recorder** modülü varsa (DS-K1F800-F vb.) bu API ile parmak izi feature vektörü toplanır.

### Akış
```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_GetDeviceAbility (ACS_ABILITY, Node: <CaptureFingerPrint>)
  → NET_DVR_StartRemoteConfig (NET_DVR_CAPTURE_FINGERPRINT_INFO = 2504)
        cond: NET_DVR_CAPTURE_FINGERPRINT_COND
        callback: fRemoteConfigCallback
        result: NET_DVR_CAPTURE_FINGERPRINT_CFG  ← parmak izi feature vektörü
  → NET_DVR_StopRemoteConfig
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### İlgili Yapılar
- `NET_DVR_CAPTURE_FINGERPRINT_COND` (s.154) — sorgulama koşulu (parmak no, kart no)
- `NET_DVR_CAPTURE_FINGERPRINT_CFG` — toplanan feature vektörü (binary, ~512 byte)

## ngsaccess Tarafında Notlar

### Online Capture Senaryosu — Admin Panel
```typescript
// convex/actions/hikvision/captureCard.ts (önerilen)
export const captureCardFromDevice = action({
  args: { deviceId: v.id("devices") },
  handler: async (ctx, { deviceId }) => {
    const device = await ctx.runQuery(...);

    // 1. Capability check
    const capRes = await fetch(
      `http://${device.deviceIp}/ISAPI/AccessControl/capabilities`,
      { headers: { Authorization: digestAuth() } }
    );
    // parse XML, check <isSupportCaptureCardInfo>

    // 2. Capture
    const captureRes = await fetch(
      `http://${device.deviceIp}/ISAPI/AccessControl/CaptureCardInfo?format=json`,
      { headers: { Authorization: digestAuth() } }
    );
    const json = await captureRes.json();
    // json.CardInfo.cardNo

    return json.CardInfo;
  },
});
```

UI senaryosu:
1. Admin panel'inde "Çalışan Ekle" formu
2. "Karttan Okut" butonu → bu action çağrılır
3. Cihaz "Kart okutunuz" mesajını gösterir, kullanıcı kart okuttur
4. Cihaz kart datasını döner, form alanları otomatik dolar
5. Admin "Kaydet" → ngsaccess + cihazlara sync

### Offline Capture Senaryosu
Bu özellik **özel** — ngsaccess SaaS model olduğu için cihazlar genelde online. Sadece **air-gapped** enterprise kurulumlarda gerekirse.

### Fingerprint Recorder
Eğer ngsaccess'te ayrı parmak izi recorder cihazı varsa (kayıt için ayrı, geçiş için ayrı), bu akış kullanılır. Standart kart okuyucularda parmak izi modülü zaten gömülü olduğu için bu nadiren gerekir.
