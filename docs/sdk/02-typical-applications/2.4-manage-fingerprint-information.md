# Parmak İzi Bilgisi Yönetimi (Manage Fingerprint Information)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.4, s.27–29

## Özet

Parmak izli erişim kontrol terminallerinde (DS-K1T804M, DS-K1A801F vb.) **çalışanın parmak izini** cihaza işlemek + sorgulamak. Yüz gibi, **karta bağlı** çalışır.

Parmak izi datası **collect (toplama)** → **apply (uygulama)** iki aşamalıdır:
1. **Collect:** Parmak izi recorder veya doğrudan cihazdan okutarak fingerprint feature vektörünü topla — [2.1 Data Collection](./2.1-data-collection.md)
2. **Apply:** Toplanmış parmak izi datasını çalışanın kart numarasına bağla ve cihaza yaz

## Önkoşullar
1. `NET_DVR_Init()` çağrılmış
2. `NET_DVR_Login_V40()` ile bağlanılmış
3. **İlgili kart cihaza işlenmiş** ([2.2 Manage Card Information](./2.2-manage-card-information.md))
4. **Parmak izi datası toplanmış** ([2.1.3 Collect Fingerprint](./2.1-data-collection.md#213-collect-fingerprint))

## İş Akışı (PDF Figure 2-5)

```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_GetDeviceAbility (ACS_ABILITY, Node: <FingerPrint>)
  → NET_DVR_StartRemoteConfig:
        Get:   CMD = NET_DVR_GET_FINGERPRINT_CFG (2150)
        Apply: CMD = NET_DVR_SET_FINGERPRINT_CFG (2151)
  → NET_DVR_SendRemoteConfig (dwDataType: ENUM_ACS_SEND_DATA)
  → NET_DVR_StopRemoteConfig
  → NET_DVR_Logout / NET_DVR_Cleanup
```

## Kullanılan API'ler
- `NET_DVR_GetDeviceAbility` — `<FingerPrint>` node desteği
- `NET_DVR_StartRemoteConfig` — `NET_DVR_GET_FINGERPRINT_CFG` (2150) / `NET_DVR_SET_FINGERPRINT_CFG` (2151)

## İlgili Yapılar
- **`NET_DVR_FINGER_PRINT_CFG_V50`** (s.181) — parmak izi konfigürasyonu
  - `byCardNo[]` — kart numarası
  - `byFingerPrintID` — parmak izi ID (her kart için max 10 parmak)
  - `dwFingerPrintLen` — parmak izi datası uzunluğu
  - `byFingerData[]` — feature vektörü (template, fotoğraf değil)
- **`NET_DVR_FINGER_PRINT_INFO_COND_V50`** (s.182) — sorgulama koşulu

## ngsaccess Tarafında Notlar

### Mevcut Yaklaşım
`docs/HIKVISION_ISAPI_FINGERPRINT_TERMINALS_DETAYLI.md`'de Pro Series parmak izi terminalleri için ISAPI rehberi detaylı.

### Parmak İzi Akışı Önerisi
ngsaccess'te parmak izi yönetimi nadir kullanılır (kart + yüz daha yaygın). Eğer gerekirse:

1. **Çalışan ekranında "Parmak izi kaydet" butonu**
   - Convex action çağrılır
   - Action cihaza `/ISAPI/AccessControl/CaptureFingerPrint?format=json` POST atar
   - Cihaz parmak izi okumayı bekler — kullanıcı parmağını basar
   - Cihaz feature vektörünü döner (base64 encoded)

2. **Feature vektörünü tüm cihazlara push**
   - Her cihaza ayrı PUT
   - `/ISAPI/AccessControl/FingerPrint/Record` veya benzer URI

### ISAPI Karşılığı
```http
PUT /ISAPI/AccessControl/FingerPrintMultiCfg/Record?format=json HTTP/1.1
Content-Type: application/json

{
  "FingerPrintCfg": {
    "employeeNo": "1001",
    "enableCardReader": [1, 2],
    "fingerPrintID": 1,
    "fingerType": "normalFP",
    "fingerData": "<base64 fingerprint template>"
  }
}
```

### Önemli Uyarılar
- Parmak izi datası **feature vektörü** (template), JPEG değil
- Her parmak için ayrı `fingerPrintID` (1-10)
- Hikvision FPR (Fingerprint Module) versiyonuna göre vektör formatı değişebilir → cihazlar arası uyumluluk kontrolü gerek
- Veritabanında **parmak izi datasını şifreli sakla** (PII)
