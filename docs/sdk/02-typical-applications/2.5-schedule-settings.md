# Takvim/Plan Ayarları (Schedule Settings)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.5, s.29–46

## Özet

Hikvision erişim kontrol cihazlarında **3 ayrı takvim sistemi** vardır. Hepsi aynı yapıda çalışır:

```
Week Plan (haftalık)  +  Holiday Plan (tatil)
         ↓                       ↓
       Holiday Group (max 16 tatil bağlanabilir)
         ↓
       Template  ←  (week plan + holiday groups kombinasyonu)
         ↓
       Card / Door / Card Reader  (template'e bağlanır)
```

### 3 Takvim Sistemi
1. **2.5.1 Authentication Mode Control Schedule** — Hangi saatlerde hangi auth yöntemi geçerli (sadece kart / kart+şifre / parmak izi / yüz vb.)
2. **2.5.2 Access Permission Control Schedule** — Hangi saatlerde erişim açık (kartın geçerli olduğu saatler)
3. **2.5.3 Door Control Schedule** — Hangi saatlerde kapı **remain open / closed / normal**

---

## 2.5.1 Authentication Mode Control Schedule

### Amaç
Kart okuyucu için **haftalık + tatil günleri** üzerinden kimlik doğrulama modunu tanımlar. Örneğin: hafta içi 09:00-18:00 = sadece kart; geceleri = kart+şifre.

### Akış
```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_GetDeviceAbility (ACS_ABILITY, Node: <CardReaderPlan>)
  → NET_DVR_SetDVRConfig — sıra önemli:
        1. NET_DVR_SET_CARD_READER_PLAN          → cmd 1
        2. NET_DVR_SET_VERIFY_PLAN_TEMPLATE      → template tanımla
        3. NET_DVR_SET_VERIFY_WEEK_PLAN          → haftalık plan
        4. NET_DVR_SET_VERIFY_HOLIDAY_GROUP      → tatil grubu
        5. NET_DVR_SET_VERIFY_HOLIDAY_PLAN       → tatil planı
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Kritik Yapılar
- `NET_DVR_CARD_READER_PLAN` — kart okuyucuyu template'e bağlar (`dwTemplateNo`)
- `NET_DVR_PLAN_TEMPLATE` — template: `byTemplateName`, `dwWeekPlanNo`, `dwHolidayGroupNo[16]`
- `NET_DVR_WEEK_PLAN_CFG` — haftalık plan (7 gün × 8 zaman dilimi)
- `NET_DVR_SINGLE_PLAN_SEGMENT` — günlük tek segment: `struTimeSegment` + `byVerifyMode`
- `NET_DVR_HOLIDAY_GROUP_CFG` — tatil grubu (max 16 tatil planı bağlanabilir)
- `NET_DVR_HOLIDAY_PLAN_CFG` — tek tatil planı: `struBeginDate`, `struEndDate`, `struPlanCfg`

### `byVerifyMode` Değerleri
| Değer | Anlam |
|---|---|
| 0 | Invalid |
| 1 | Sleepy (kapalı) |
| 2 | Card + Password |
| 3 | Card only |
| 4 | Card OR Password |
| 5 | Fingerprint |
| 6 | Fingerprint + Password |
| 7 | Fingerprint OR Card |
| 8 | Fingerprint + Card |
| 9 | Fingerprint + Card + Password |

### Örnek (Card Reader Plan Set)
```c
// 1) Card reader 1 → template 1
NET_DVR_CARD_READER_PLAN struCardReaderPlan = {0};
struCardReaderPlan.dwSize       = sizeof(struCardReaderPlan);
struCardReaderPlan.dwTemplateNo = 1;
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_CARD_READER_PLAN, 1,
    &struCardReaderPlan, sizeof(struCardReaderPlan));

// 2) Template 1 → week plan 2 + holiday group 2
NET_DVR_PLAN_TEMPLATE struPlanTem = {0};
struPlanTem.dwSize         = sizeof(struPlanTem);
struPlanTem.byEnable       = 1;
strncpy((char*)struPlanTem.byTemplateName, "card reader auth template 1",
        TEMPLATE_NAME_LEN);
struPlanTem.dwWeekPlanNo       = 2;
struPlanTem.dwHolidayGroupNo[0] = 2;  // max 16 tatil bağlanabilir
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_VERIFY_PLAN_TEMPLATE, 1,
    &struPlanTem, sizeof(struPlanTem));

// 3) Week plan 2: 00:00-23:59:59 sadece card+password (mode 4)
NET_DVR_WEEK_PLAN_CFG struWeekPlan2 = {0};
struWeekPlan2.dwSize    = sizeof(struWeekPlan2);
struWeekPlan2.byEnable  = 1;

NET_DVR_SINGLE_PLAN_SEGMENT struSeg = {0};
struSeg.byEnable    = 1;
struSeg.byVerifyMode = 4;  // card or password
struSeg.struTimeSegment.struBeginTime.byHour = 0;
struSeg.struTimeSegment.struEndTime.byHour   = 23;
struSeg.struTimeSegment.struEndTime.byMinute = 59;
struSeg.struTimeSegment.struEndTime.bySecond = 59;

for (int iDate = 0; iDate < MAX_DAYS; iDate++) {
    memcpy(&struWeekPlan2.struPlanCfg[iDate][0], &struSeg, sizeof(struSeg));
}
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_VERIFY_WEEK_PLAN, 2,
    &struWeekPlan2, sizeof(struWeekPlan2));

// 4-5) Holiday group + holiday plan benzer şekilde
```

## 2.5.2 Access Permission Control Schedule

### Amaç
**Bazı kapıların hangi saatlerde aktif olduğunu** kontrol eder. Default 7×24 — bu API ile kısıtlanabilir.

### Akış
```
NET_DVR_GetDeviceAbility (Node: <CardRightPlan>)  ← destekli mi?
  → NET_DVR_SetDVRConfig:
       NET_DVR_SET_CARD_RIGHT_WEEK_PLAN    (cmd 2127)
       NET_DVR_SET_CARD_RIGHT_HOLIDAY_PLAN (cmd 2131)
       NET_DVR_SET_CARD_RIGHT_HOLIDAY_GROUP (cmd 2135)
       NET_DVR_SET_CARD_RIGHT_PLAN_TEMPLATE (cmd 2139)
```

Aynı veri yapıları (`NET_DVR_WEEK_PLAN_CFG`, `NET_DVR_HOLIDAY_PLAN_CFG`, `NET_DVR_HOLIDAY_GROUP_CFG`, `NET_DVR_PLAN_TEMPLATE`) bu plan için de kullanılır.

> **Önemli:** Template oluşturulduktan sonra **kişi uygulanırken `wCardRightPlan[door][slot]` alanına template no yazılır** (bkz. [2.2-manage-card-information.md](./2.2-manage-card-information.md)).

## 2.5.3 Door Control Schedule

### Amaç
Kapının fiziksel durumunu kontrol eder:
- **Remain Open** (sürekli açık — auth gerekmez)
- **Remain Closed** (kapalı — kimse geçemez)
- **Normal** (auth + kart ile geçilir)

### Akış
```
NET_DVR_GetDeviceAbility (Node: <DoorStatusPlan>)
  → NET_DVR_SetDVRConfig:
       NET_DVR_SET_WEEK_PLAN_CFG               (cmd 2101)
       NET_DVR_SET_DOOR_STATUS_HOLIDAY_PLAN    (cmd 2103)
       NET_DVR_SET_DOOR_STATUS_HOLIDAY_GROUP   (cmd 2105)
       NET_DVR_SET_DOOR_STATUS_PLAN_TEMPLATE   (cmd 2107)
       NET_DVR_SET_DOOR_STATUS_PLAN            (cmd 2111)
```

### Kritik Struct
- `NET_DVR_DOOR_STATUS_PLAN` — kapı no → template no eşlemesi
- `NET_DVR_SINGLE_PLAN_SEGMENT.byDoorStatus`:
  | Değer | Anlam |
  |---|---|
  | 0 | Invalid |
  | 1 | Sleepy |
  | 2 | Remain Open |
  | 3 | Remain Closed |

### Örnek (Door Status Plan)
```c
// Door 1 → template 1
NET_DVR_DOOR_STATUS_PLAN struDoorStatusPlan = {0};
struDoorStatusPlan.dwSize       = sizeof(struDoorStatusPlan);
struDoorStatusPlan.dwTemplateNo = 1;
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_DOOR_STATUS_PLAN, 1,
    &struDoorStatusPlan, sizeof(struDoorStatusPlan));

// Template 1 → week plan 1 + holiday group 1
NET_DVR_PLAN_TEMPLATE struPlanTem = {0};
struPlanTem.byEnable        = 1;
struPlanTem.dwWeekPlanNo    = 1;
struPlanTem.dwHolidayGroupNo[0] = 1;
strncpy((char*)struPlanTem.byTemplateName, "door status schedule template 1",
        TEMPLATE_NAME_LEN);
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_DOOR_STATUS_PLAN_TEMPLATE, 1,
    &struPlanTem, sizeof(struPlanTem));

// Week plan 1: hep remain open (mode 2)
NET_DVR_SINGLE_PLAN_SEGMENT struSeg = {0};
struSeg.byEnable     = 1;
struSeg.byDoorStatus = 2;  // remain open
struSeg.struTimeSegment.struEndTime.byHour   = 23;
struSeg.struTimeSegment.struEndTime.byMinute = 59;
struSeg.struTimeSegment.struEndTime.bySecond = 59;
```

## ngsaccess Tarafında Notlar

### Sadeleştirme Önerisi
Çoğu ngsaccess kullanıcısı (KOBİ ölçeğinde) **karmaşık takvim istemez** — çalışanlar hafta içi mesai saati, hafta sonu kapalı gibi basit kurallarla yetinir. Bu yüzden ngsaccess'te:

1. **Default template** kullan — Hikvision cihazlarında default 7×24 template vardır
2. **Sadece spesifik kullanıcılar için custom template** gerekirse `accessGroup`'lara takvim bilgisi ekle
3. Take care: Cihaz reset'lendiğinde takvimleri yeniden yüklemen gerekir → `convex/actions/hikvisionSync.ts` içinde takvim push fonksiyonu olmalı

### Hangi Plan Ne İçin?
| ngsaccess senaryosu | Hangi plan |
|---|---|
| "Geceleri kart+şifre, gündüz sadece kart" | **2.5.1 Auth Mode Schedule** |
| "Sadece mesai saatlerinde geçiş izni" | **2.5.2 Access Permission Schedule** (`accessRules` tablo) |
| "Cuma günleri 18:00'dan sonra kapı hep açık" | **2.5.3 Door Control Schedule** |

### Holiday Yönetimi
`holidays` tablosunda tanımlı tüm tatiller cihazlara `NET_DVR_HOLIDAY_PLAN_CFG` ile push edilir. Max 16 tatil planı / grup. ngsaccess'te tatil sayısı > 16 olursa "öncelikli olanları" seç.
