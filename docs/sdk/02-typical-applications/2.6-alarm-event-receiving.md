# Alarm ve Event Alma (Alarm and Event Receiving)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.6, s.47–63

## Özet

Hikvision erişim kontrol cihazlarından **kart okuma, kapı açılma/kapanma, alarm tetikleme** gibi event'leri üçüncü taraf bir platform (ngsaccess Convex backend) tarafından almak için kullanılır. SDK iki çalışma modu sunar:

- **Arming Mode (Bağlanan istemci modu):** Platform cihaza bağlanır, cihaz bu açık bağlantı üzerinden event yollar. Tek cihazla persistan TCP/HTTP bağlantısı gerekir.
- **Listening Mode (Listening sunucu modu):** Platform bir TCP port açar, cihazlar bu porta event POST eder. **Birden fazla cihaz** aynı sunucuya yollayabilir; cihaz restart olursa bağlantı yeniden kurulur. ngsaccess için **bu mod önerilir** (`/card-reader` HTTP endpoint zaten bu mantıkta çalışıyor).

ngsaccess tarafında Convex'in `/card-reader` HTTP endpoint'i Listening Mode'un HTTP karşılığıdır — cihaz POST atar, Convex işler, 200 döner.

## 2.6.1 Erişim Kontrol Event'lerini Yapılandırma (Configure Access Control Event)

### Amaç
Hangi event'lerin (kapı açıldı, kart okutuldu, alarm input vs.) hangi action'lara (recording, alarm output, buzzing, capture) bağlanacağını cihaz tarafında yapılandırır. **"Event Card Linkage"** denen kavram bu.

### Akış (PDF Figure 2-9, s.49)
```
NET_DVR_Init
  → NET_DVR_Login_V40
  → NET_DVR_GetDeviceAbility (dwAbilityType: ACS_ABILITY)
        Capability: AcsAbility; Node: <EventLinkage>
  → NET_DVR_GetDeviceConfig (CMD: NET_DVR_GET_EVENT_CARD_LINKAGE_CFG_V51)  [opsiyonel]
  → NET_DVR_SetDeviceConfig (CMD: NET_DVR_SET_EVENT_CARD_LINKAGE_CFG_V51)
  → Receive event/alarm (arming/listening mode)
        Callback CMD: COMM_ALARM_ACS
        Struct: NET_DVR_ACS_ALARM_INFO
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Kullanılan API'ler
- `NET_DVR_GetDeviceAbility` — `<EventLinkage>` node'unun varlığını kontrol et
- `NET_DVR_GetDeviceConfig` — mevcut linkage'ı oku (cmd `NET_DVR_GET_EVENT_CARD_LINKAGE_CFG_V51`, no: 2518)
- `NET_DVR_SetDeviceConfig` — yeni linkage yaz (cmd `NET_DVR_SET_EVENT_CARD_LINKAGE_CFG_V51`, no: 2519)

### İlgili Yapılar
- `NET_DVR_EVENT_CARD_LINKAGE_COND` — sorgu/yazma koşulu (`dwEventID`, `dwCount=1`)
- `NET_DVR_EVENT_CARD_LINKAGE_CFG_V50` — linkage konfigürasyonu
  - `byProMode` — 0: event linkage, 1: card no linkage
  - `byCapturePic` — capture açık mı (0/1)
  - `dwEventSourceID` — 0xffffffff = tüm kaynaklar
  - `uLinkageInfo.struEventLinkage.wMainEventType` — 0: device, 1: alarm input, 2: door, 3: card reader
  - `uLinkageInfo.struEventLinkage.wSubEventType` — örn. 10: kapı magnetic switch ile açıldı
- `NET_DVR_ACS_CFG` — controller-level config (`byUploadCapPic = 1` ise capture upload edilir)
- `NET_DVR_ACS_ALARM_INFO` — callback ile gelen alarm/event payload

### Örnek (capture linkage etkinleştirme, kapı açıldığında resim çekme)
```c
// 1) Callback (gelen event burada işlenir — sadece data kopyala, ağır iş yapma)
BOOL CALLBACK MSesGCallback(LONG lCommand, NET_DVR_ALARMER *pAlarmer,
                            char *pAlarmInfo, DWORD dwBufLen, void* pUser) {
    switch (lCommand) {
    case COMM_ALARM_ACS: {  // 0x5002 — access controller alarm
        NET_DVR_ACS_ALARM_INFO struAcsAlarmInfo = {0};
        memcpy(&struAcsAlarmInfo, pAlarmInfo, sizeof(struAcsAlarmInfo));

        char szCardNo[50] = {0};
        sprintf(szCardNo, "CardNo:%s", (char *)struAcsAlarmInfo.struAcsEventInfo.byCardNo);
        BYTE  byCardType    = struAcsAlarmInfo.struAcsEventInfo.byCardType;
        DWORD dwCardReaderNo = struAcsAlarmInfo.struAcsEventInfo.dwCardReaderNo;
        DWORD dwDoorNo       = struAcsAlarmInfo.struAcsEventInfo.dwDoorNo;

        if (struAcsAlarmInfo.dwPicDataLen > 0 && struAcsAlarmInfo.pPicData != NULL) {
            // capture image kaydet
            FILE *fSnap = fopen("snap.jpg","wb");
            fwrite(struAcsAlarmInfo.pPicData, struAcsAlarmInfo.dwPicDataLen, 1, fSnap);
            fclose(fSnap);
        }
        break;
    }
    default: break;
    }
    return TRUE;
}

// 2) main: init → login → callback → setup alarm channel → set linkage cfg → bekle
NET_DVR_Init();
NET_DVR_SetConnectTime(2000, 1);
NET_DVR_SetReconnect(10000, true);

NET_DVR_USER_LOGIN_INFO struLoginInfo = {0};
strcpy(struLoginInfo.sDeviceAddress, "192.168.1.64");
struLoginInfo.wPort = 8000;
strcpy(struLoginInfo.sUserName, "admin");
strcpy(struLoginInfo.sPassword, "abcd1234");
NET_DVR_DEVICEINFO_V40 struDeviceInfoV40 = {0};
LONG lUserID = NET_DVR_Login_V40(&struLoginInfo, &struDeviceInfoV40);

// callback set + alarm channel aç (V41 wrapper, internally V31 callback)
NET_DVR_SetDVRMessageCallBack_V31(MSesGCallback, NULL);
NET_DVR_SETUPALARM_PARAM struSetupParam = {0};
struSetupParam.dwSize = sizeof(NET_DVR_SETUPALARM_PARAM);
LONG lHandle = NET_DVR_SetupAlarmChan_V41(lUserID, &struSetupParam);

// Capture linkage configure
NET_DVR_EVENT_CARD_LINKAGE_COND struEventCardLinkageCond = {0};
struEventCardLinkageCond.dwSize    = sizeof(NET_DVR_EVENT_CARD_LINKAGE_COND);
struEventCardLinkageCond.dwEventID = 1;

NET_DVR_EVENT_CARD_LINKAGE_CFG_V50 struEventCardLinkageCfgV50 = {0};
struEventCardLinkageCfgV50.dwSize        = sizeof(NET_DVR_EVENT_CARD_LINKAGE_CFG_V50);
struEventCardLinkageCfgV50.byProMode     = 0;            // event linkage
struEventCardLinkageCfgV50.byCapturePic  = 1;            // capture ON
struEventCardLinkageCfgV50.dwEventSourceID = 0xffffffff; // tüm kaynaklar
struEventCardLinkageCfgV50.uLinkageInfo.struEventLinkage.wMainEventType = 2;  // door event
struEventCardLinkageCfgV50.uLinkageInfo.struEventLinkage.wSubEventType  = 10; // magnetic switch açıldı

DWORD dwStatus = 0;
NET_DVR_SetDeviceConfig(lUserID, NET_DVR_SET_EVENT_CARD_LINKAGE_CFG_V50, 1,
    &struEventCardLinkageCond, sizeof(struEventCardLinkageCond),
    &dwStatus,
    &struEventCardLinkageCfgV50, sizeof(struEventCardLinkageCfgV50));

// Controller: capture'ı upload et
NET_DVR_ACS_CFG struAcsCfg = {0};
struAcsCfg.dwSize         = sizeof(NET_DVR_ACS_CFG);
struAcsCfg.byUploadCapPic = 1;
NET_DVR_SetDVRConfig(lUserID, NET_DVR_SET_ACS_CFG, 0,
    &struAcsCfg, sizeof(struAcsCfg));

Sleep(30000);
NET_DVR_CloseAlarmChan_V30(lHandle);
NET_DVR_Logout(lUserID);
NET_DVR_Cleanup();
```

> **Önemli:** Callback içinde ağır iş yapma, başka HCNetSDK API çağırma. Mesajı PostMessage / kuyruğa koy, asıl işlemeyi worker thread yapsın.

## 2.6.2 Arming Mode'da Event Alma

### Amaç
Platform (server) cihaza bağlanır ve "arm" komutu yollar; cihaz event'leri bu bağlantı üzerinden yollar.

### Akış (PDF Figure 2-10, s.55)
```
NET_DVR_Init
  → NET_DVR_Login_V40
  → NET_DVR_SetDVRMessageCallBack_V50  ← callback set
  → NET_DVR_SetupAlarmChan_V50         ← arm
  → (callback'ten event'ler gelir)
  → NET_DVR_CloseAlarmChan_V30
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Subscribe ile Filtreleme
SetupAlarmChan'a XML subscribe payload geçerek hangi event'lerin geleceği filtrelenebilir:
```c
char szSubscribe[1024] = {0};
memcpy(szSubscribe,
    "<SubscribeEvent version=\"2.0\" xmlns=\"http://www.isapi.org/ver20/XMLSchema\">\r\n"
    "<eventMode>all</eventMode>\r\n", 1024);

NET_DVR_SETUPALARM_PARAM_V50 struSetupParamV50 = {0};
struSetupParamV50.dwSize          = sizeof(NET_DVR_SETUPALARM_PARAM_V50);
struSetupParamV50.byAlarmInfoType = 1;
struSetupParamV50.byLevel         = 1;
LONG lHandle = NET_DVR_SetupAlarmChan_V50(lUserID, &struSetupParamV50,
                                          szSubscribe, strlen(szSubscribe));
```

### Text Protocol (ISAPI) için Callback
- `lCommand` = `COMM_ISAPI_ALARM` (0x6009)
- `pAlarmInfo` cast: `NET_DVR_ALARM_ISAPI_INFO *`
- HCNetSDK yerine **text protocol** üzerinden gelen alarm'lar için bu kullanılır.

### Kullanılan API'ler
- `NET_DVR_SetDVRMessageCallBack_V50` — callback set
- `NET_DVR_SetupAlarmChan_V50` — arm (subscribe XML opsiyonel)
- `NET_DVR_CloseAlarmChan_V30` — disarm

## 2.6.3 Listening Mode'da Event Alma ⭐

> **ngsaccess için en uygun mod.** Convex `/card-reader` HTTP endpoint zaten "listening" mantığında çalışıyor.

### Amaç
Cihaz, önceden tanımlanmış bir sunucu adresine event'leri otomatik POST eder. Birden fazla cihaz aynı sunucuyu kullanabilir; cihaz restart olunca bağlantı kendini toparlar.

### Akış (PDF Figure 2-11, s.58)
```
NET_DVR_Init
  → NET_DVR_Login_V40                                 [opsiyonel]
  → NET_DVR_GetDVRConfig (NET_DVR_GET_NETCFG_V50)     [opsiyonel — mevcut adresleri oku]
  → NET_DVR_SetDVRConfig (NET_DVR_SET_NETCFG_V50)     ← listening host adres + port set et
        cmd no: 1016
        struct: NET_DVR_NETCFG_V50
  → NET_DVR_StartListen_V30                            ← callback + listening başlat
  → (cihaz event POST eder, callback tetiklenir)
  → NET_DVR_StopListen_V30
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Önemli Notlar
- Cihaz **en fazla 1-2 listening host** destekler (alarm host).
- HCNetSDK üzerinden gelen alarm için `lCommand` farklı olur — config sırasında set ettiğin event tipine göre.
- Text protocol (ISAPI) üzerinden gelen alarm için `lCommand = COMM_ISAPI_ALARM`, struct `NET_DVR_ALARM_ISAPI_INFO`.

### Kullanılan API'ler
- `NET_DVR_GetDVRConfig` / `NET_DVR_SetDVRConfig` — listening adresleri yönet (`NET_DVR_NETCFG_V50`)
- `NET_DVR_StartListen_V30` — listening thread başlat
- `NET_DVR_StopListen_V30` — durdur

### Örnek
```c
NET_DVR_Init();
NET_DVR_SetConnectTime(2000, 1);
NET_DVR_SetReconnect(10000, true);

LONG lUserID = NET_DVR_Login_V30("172.0.0.100", 8000, "admin", "12345",
                                 &struDeviceInfo);

LONG lHandle = NET_DVR_StartListen_V30(NULL, 7200, MessageCallback, NULL);
Sleep(5000);
NET_DVR_StopListen_V30(lHandle);
NET_DVR_Logout(lUserID);
NET_DVR_Cleanup();
```

## 2.6.4 Erişim Kontrol Event'lerini Sorgulama (Search)

### Amaç
Üçüncü taraf platform önceden gelen ve saklanmış event'leri sorgulamak için kullanır (filtrele: tarih aralığı, kart no, kapı no vb.).

### Akış (PDF Figure 2-12, s.61)
```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_STDXMLConfig (GET /ISAPI/AccessControl/GetAcsEvent/capabilities)  [opsiyonel]
  → NET_DVR_StartRemoteConfig (CMD: NET_DVR_GET_ACS_EVENT, 2514)
        cond: NET_DVR_ACS_EVENT_COND
        callback: fRemoteConfigCallback
        result: NET_DVR_ACS_EVENT_CFG
  → NET_DVR_STDXMLConfig (POST /ISAPI/AccessControl/AcsEventTotalNum)         [opsiyonel — toplam sayı]
  → NET_DVR_StopRemoteConfig
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### ISAPI Alternatifi
HCNetSDK kullanmadan doğrudan HTTP:
- `GET /ISAPI/AccessControl/GetAcsEvent/capabilities`
- `POST /ISAPI/AccessControl/AcsEventTotalNum?format=json`
- `POST /ISAPI/AccessControl/AcsEvent?format=json`

### İlgili Yapılar
- `NET_DVR_ACS_EVENT_COND` — search filter
- `NET_DVR_ACS_EVENT_CFG` — döner her event
- `JSON_AcsEventTotalNumCond` — JSON karşılığı

## ngsaccess Tarafında Notlar

### Mevcut Mimari
- [convex/http.ts](../../../convex/http.ts) — `/card-reader` HTTP POST endpoint. Hikvision **Listening Mode (HTTP Notify Surveillance Center)** ile birebir uyumlu.
- [convex/lib/cardReaderParse.ts](../../../convex/lib/cardReaderParse.ts) — gelen body'i parse eder. `NET_DVR_ACS_ALARM_INFO`'daki `byCardNo`, `dwDoorNo` alanları JSON'da `cardNo`, `doorNo` olarak gelir (ISAPI HTTP Notification format).
- [docs/HETZNER_CARD_READER_BRIDGE.md](../../HETZNER_CARD_READER_BRIDGE.md) — ESP32/Hetzner bridge mimarisi.

### Hangi Mod Hangi Senaryoya?

| Senaryo | Mod | ngsaccess karşılığı |
|---|---|---|
| Hikvision cihaz → ngsaccess Convex'e direkt event | **Listening (HTTP Notify)** | Cihaza `https://<deployment>.convex.site/card-reader` URL'i ver. Cihaz POST atar, Convex parse eder. |
| Cihaz LAN'da, internet yok | Arming (HCNetSDK) | Yerel bridge process (Hetzner üzerinde) cihaza bağlanır, event'leri Convex'e relay eder. |
| Geçmiş event'leri sorgulama (raporlama) | Search (`AcsEvent?format=json`) | Convex action içinden ISAPI HTTP isteği |

### Cihaz Yapılandırma (Listening Mode, HTTP Notify)
Hikvision web arayüzü → **Configuration → Event → Linkage Method → Notify Surveillance Center**:
- **Server URL:** `https://<convex-deployment>.convex.site/card-reader`
- **Event Type:** Access Control / Card Swiped seçili
- **HTTP method:** POST, format JSON

Cihaz event olunca bu URL'e POST atar. Body örnek:
```json
{
  "ipAddress": "192.168.1.64",
  "portNo": 80,
  "protocolType": "HTTP",
  "macAddress": "xx:xx:...",
  "channelID": 1,
  "dateTime": "2026-05-16T10:30:00+03:00",
  "activePostCount": 1,
  "eventType": "AccessControllerEvent",
  "eventState": "active",
  "eventDescription": "Access Controller Event",
  "AccessControllerEvent": {
    "deviceName": "Access Controller",
    "majorEventType": 5,
    "subEventType": 75,
    "cardNo": "12345678",
    "cardType": 1,
    "name": "Ahmet",
    "employeeNoString": "1001",
    "serialNo": 123,
    "userType": "normal",
    "currentVerifyMode": "cardOrFace",
    "frontSerialNo": 122,
    "attendanceStatus": "undefined",

```
