# Durum İzleme (Status Monitoring)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.8, s.67–71

## Özet

Cihazın anlık çalışma durumunu sorgulamak için kullanılır:
- Erişim kontrolcü çalışma durumu (online, alarm, kapı durumları)
- Turnike (gate) genel durumu
- Aktif IR (kızılötesi) intrusion detector durumu
- Turnike parça durumu (sensor, motor, lamp board vb.)
- Attendance (puantaj) modu yönetimi

ngsaccess'te dashboard'daki "cihaz canlı mı?" + "kapılar açık mı?" göstergeleri için bu bölüm kullanılır.

---

## Erişim Kontrolcü Çalışma Durumu

### Yetenek Kontrolü
```c
NET_DVR_GetDeviceAbility(lUserID, ACS_ABILITY, &struCondBuf, dwCondSize,
                         &struOutBuf, dwOutSize);
// XML_AcsAbility içinde <AcsWorkStatus> node'u var mı?
```

### Çağrı
```c
NET_DVR_GetDVRConfig(lUserID, NET_DVR_GET_ACS_WORK_STATUS_V50, 0,
                     &struWorkStatus, sizeof(NET_DVR_ACS_WORK_STATUS_V50));
// cmd no: 2180
```

### Dönen Struct: `NET_DVR_ACS_WORK_STATUS_V50`
Cihaz durumu hakkında zengin bilgi içerir (PDF s.147 ve bizim [04-structures-enumerations.md](../04-structures-enumerations.md)):
- Çalışma süresi, sıcaklık, voltaj
- Her kapı için: kapı durumu (open/closed/alarm), magnetic switch durumu
- Her kart okuyucu için: online/offline, son ping
- Network status
- Battery / AC status (Face Recognition Terminal'lerde)

## Genel Turnike Durumu (Gate Status)

Sadece **turnike (lane controller)** içeren modellerde geçerli.

| İşlem | URI | Method | Response |
|---|---|---|---|
| Yetenek kontrolü | `/ISAPI/AccessControl/GateStatus/capabilities` | GET | `XML_Cap_GateStatus` |
| Durum al | `/ISAPI/AccessControl/GateStatus` | GET | `XML_GateStatus` |

> Cihaz destekliyor mu? `GET /ISAPI/AccessControl/capabilities` → `<isSupportGateStatus>true</isSupportGateStatus>`

## 2.8.1 Attendance (Puantaj) Modu

### Amaç
Cihaza kart okutulduğunda **mesai başlangıcı, mesai bitişi, mola, fazla mesai** gibi state'lerden hangisinin işaretleneceğini belirler.

### Modlar
- **Manuel:** Çalışan cihazda butona basıp state seçer (check in / out / break in / out / overtime in / out)
- **Otomatik:** Cihaz takvime göre otomatik atar (sabah → check in, akşam → check out)
- **Disabled:** Attendance kapalı, sadece erişim kontrol

### Akış (PDF Figure 2-14, s.70)
```
NET_DVR_Init → NET_DVR_Login_V40
  → NET_DVR_STDXMLConfig:
       GET  /ISAPI/AccessControl/attendanceStatusModeCfg/capabilities?format=json
       GET  /ISAPI/AccessControl/attendanceStatusModeCfg?format=json
       PUT  /ISAPI/AccessControl/attendanceStatusModeCfg?format=json   ← mode set
  → NET_DVR_STDXMLConfig:
       GET  /ISAPI/AccessControl/attendanceStatusRuleCfg/capabilities?format=json
       GET  /ISAPI/AccessControl/attendanceStatusRuleCfg?attendanceStatus=checkIn&format=json
       PUT  /ISAPI/AccessControl/attendanceStatusRuleCfg?attendanceStatus=checkIn&format=json  ← rule set
  → NET_DVR_Logout / NET_DVR_Cleanup
```

### Önemli Notlar
- Attendance ayarlamadan önce **en az 1 kart** cihaza işlenmiş olmalı ([2.2 Manage Card Information](./2.2-manage-card-information.md))
- `attendanceStatus` query parametresi her status için ayrı kural gerektirir:
  - `checkIn` — mesai başlangıcı
  - `checkOut` — mesai bitişi
  - `breakIn` — mola dönüş
  - `breakOut` — mola çıkış
  - `overtimeIn` — fazla mesai başlangıç
  - `overtimeOut` — fazla mesai bitişi

### Payload Örnekleri

**Mode set:**
```json
{ "AttendanceStatusModeCfg": { "mode": "auto" } }   // auto | manual | disable
```

**Rule set (her status için ayrı):**
```json
{
  "AttendanceStatusRuleCfg": {
    "scheduleTemplate": [
      { "weekNo": 1, "timeRange": [{ "id": 1, "beginTime": "08:00:00", "endTime": "09:30:00" }] },
      { "weekNo": 2, "timeRange": [{ "id": 1, "beginTime": "08:00:00", "endTime": "09:30:00" }] }
    ]
  }
}
```

## ngsaccess Tarafında Notlar

### Periyodik Status Polling
ngsaccess'in dashboard'unda cihaz durumu için **Convex scheduler** ile periyodik polling önerilir:

```typescript
// convex/crons.ts
import { cronJobs } from "convex/server";
import { internal } from "./_generated/api";

const crons = cronJobs();
crons.interval(
  "poll device status",
  { minutes: 5 },
  internal.actions.pollHikvisionStatus.run,
);
export default crons;
```

`pollHikvisionStatus` action her cihaz için:
1. `GET /ISAPI/System/deviceInfo` → online mı?
2. `GET /ISAPI/AccessControl/capabilities` → gate destekliyor mu?
3. Gate destekliyorsa `GET /ISAPI/AccessControl/GateStatus` → durum bilgisi

Sonuçları `deviceStatuses` tablosunda tut, dashboard'dan oku.

### Attendance (PDKS) Entegrasyonu
ngsaccess'te zaten PDKS modülü var. İki yol:
1. **Cihazda attendance modu KAPALI tut** — cihaz sadece access event yollasın, ngsaccess kendisi check in/out hesaplasın (mesai saatlerine göre). Mevcut yaklaşım.
2. **Cihazda attendance modu AÇIK** — cihaz event'i `attendanceStatus` ile yollar, ngsaccess sadece kaydetsin. Daha tutarlı ama cihaz yapılandırması gerekir.

**Tavsiye:** Yöntem 1 (mevcut) — esnek, cihaz farkı yok.
