# Kart Bilgisi Yönetimi (Manage Card Information)

> **Kaynak:** Device Network SDK (Card-Based Access Control) Developer Guide V6.1.5.X — Bölüm 2.2, s.16–25

## Özet

Hikvision erişim kontrol cihazlarında **kart**, sistemin temel birimidir. Çalışanın yüz bilgisi, parmak izi, kapı yetkileri hep bir karta bağlanır. Cihazı kullanmadan önce çalışanın **kart bilgilerini cihaza işlemek (apply) veya cihazdan sorgulamak (get)** gerekir.

ngsaccess tarafında çalışan eklendiğinde `employees.cardNumber` alanı, Hikvision cihazlarına bu API ile **senkronize edilir** — `convex/actions/hikvisionSync.ts` action'u bunu yapar.

---

## İş Akışı (PDF Figure 2-3, s.17)

```
NET_DVR_Init
  → NET_DVR_Login_V40
  → NET_DVR_GetDeviceAbility (dwAbilityType: ACS_ABILITY, Node: <Card>)  [yetenek kontrolü]
  → NET_DVR_StartRemoteConfig
        Get:   CMD = NET_DVR_GET_CARD_CFG_V50 (2178)
        Apply: CMD = NET_DVR_SET_CARD_CFG_V50 (2179)
        callback: fRemoteConfigCallback
  → NET_DVR_SendRemoteConfig
        dwDataType: ENUM_ACS_SEND_DATA
        - Get   için: NET_DVR_CARD_CFG_SEND_DATA (arama koşulu — kart no)
        - Apply için: NET_DVR_CARD_CFG_V50 (kart konfigürasyonu)
  → NET_DVR_StopRemoteConfig
  → NET_DVR_Logout / NET_DVR_Cleanup
```

> **Not:** Apply etmeden önce **erişim izni programını (access permission schedule template)** ayarlamak iyi olur — kartı template'e bağlarsan o template'in haftalık/tatil takvimi kart için geçerli olur. Yoksa default template kullanılır. Detay: [2.5-schedule-settings.md](./2.5-schedule-settings.md).

---

## Kullanılan API'ler

- `NET_DVR_GetDeviceAbility` — kart yönetimi destekli mi (`<Card>` node'u kontrol)
- `NET_DVR_StartRemoteConfig` — persistan bağlantı + callback set
- `NET_DVR_SendRemoteConfig` — gerçek payload'u yolla
- `NET_DVR_StopRemoteConfig` — bağlantıyı kapat

---

## İlgili Yapılar

- **`NET_DVR_CARD_CFG_COND`** — `dwCardNum` (uygulanacak kart sayısı), `byCheckCardNo` (kart no kontrolü, 0/1), `wLocalControlID` (offline distributed controller ID — 0: ana kontrolcü)
- **`NET_DVR_CARD_CFG_SEND_DATA`** — kart numarası ile sorgulama
- **`NET_DVR_CARD_CFG_V50`** — kart konfigürasyonu (aşağıda detay)

### `NET_DVR_CARD_CFG_V50` Önemli Alanlar

| Alan | Tip | Anlam |
|---|---|---|
| `dwModifyParamType` | DWORD | Hangi alanlar düzenlenecek (bitfield, her bit bir alan; 0xFFFFFFFF = hepsi) |
| `byCardNo[]` | BYTE[32] | Kart numarası |
| `byCardValid` | BYTE | 0: geçersiz, 1: geçerli |
| `byCardType` | BYTE | 1: normal kart (default) |
| `byLeaderCard` | BYTE | First Card (lider kart) mı? 0/1 |
| `byDoorRight[256]` | BYTE[] | Kapı 1–256 için 1=yetkili, 0=yetkisiz |
| `byBelongGroup[128]` | BYTE[] | Grup 1–128 için 1=üye, 0=değil |
| `byCardPassword[8]` | BYTE | Kart şifresi |
| `wCardRightPlan[8][8]` | WORD | `[doorIdx][slot]` — kapı başına en fazla 8 schedule template |
| `dwMaxSwipeTime` | DWORD | Max kart okutma sayısı (0 = limitsiz) |
| `dwSwipeTime` | DWORD | Şimdiye kadar kaç kez okutuldu |
| `struValid` | NET_DVR_VALID_PERIOD_CFG | `byEnable` + `struBeginTime` + `struEndTime` (geçerlilik aralığı) |

## Örnek (PDF s.18-23)

> **C/C++ örnek** — kart sorgulama + kart kaydetme

```c
#include <stdio.h>
#include <iostream>
#include <afx.h>
#include "Windows.h"
#include "HCNetSDK.h"
using namespace std;

LONG m_lSetCardCfgHandle;
LONG m_lGetCardCfgHandle;
CString m_csCardNo;
CString m_csCardPassword;
BOOL bGetCardCfgFinish = FALSE;
BOOL bSetCardCfgFinish = FALSE;

// Get card callback
void CALLBACK g_fGetGatewayCardCallback(DWORD dwType, void* lpBuffer,
                                        DWORD dwBufLen, void* pUserData) {
    if (dwType == NET_SDK_CALLBACK_TYPE_DATA) {
        LPNET_DVR_CARD_CFG_V50 lpCardCfg = new NET_DVR_CARD_CFG_V50;
        memcpy(lpCardCfg, lpBuffer, sizeof(*lpCardCfg));
        // PostMessage queue'ya at — burada ağır iş yapma
    } else if (dwType == NET_SDK_CALLBACK_TYPE_STATUS) {
        DWORD dwStatus = *(DWORD*)lpBuffer;
        if (dwStatus == NET_SDK_CALLBACK_STATUS_SUCCESS) {
            bGetCardCfgFinish = TRUE;
        } else if (dwStatus == NET_SDK_CALLBACK_STATUS_FAILED) {
            DWORD dwErrCode = *(DWORD*)((char*)lpBuffer + 4);
            // Hata kodu işle
        }
    }
}

// Apply card callback
void CALLBACK g_fSetGatewayCardCallback(DWORD dwType, void* lpBuffer,
                                        DWORD dwBufLen, void* pUserData) {
    if (dwType != NET_SDK_CALLBACK_TYPE_STATUS) return;
    DWORD dwStatus = *(DWORD*)lpBuffer;

    if (dwStatus == NET_SDK_CALLBACK_STATUS_PROCESSING) {
        // gönderiliyor
    } else if (dwStatus == NET_SDK_CALLBACK_STATUS_FAILED) {
        DWORD dwErrCode = *(DWORD*)((char*)lpBuffer + 1);
        // hata
    } else if (dwStatus == NET_SDK_CALLBACK_STATUS_SUCCESS) {
        bSetCardCfgFinish = TRUE;
    } else if (dwStatus == NET_SDK_CALLBACK_STATUS_EXCEPTION) {
        bSetCardCfgFinish = TRUE;
    }
}

void main() {
    NET_DVR_Init();
    NET_DVR_SetConnectTime(2000, 1);
    NET_DVR_SetReconnect(10000, true);

    NET_DVR_DEVICEINFO_V30 struDeviceInfo;
    LONG lUserID = NET_DVR_Login_V30("192.0.0.64", 8000, "admin", "12345",
                                    &struDeviceInfo);

    // ---- GET CARD INFORMATION ----
    NET_DVR_CARD_CFG_COND struCond = {0};
    struCond.dwSize       = sizeof(struCond);
    struCond.dwCardNum    = 1;  // tek kart sorgula
    struCond.byCheckCardNo = 1;

    NET_DVR_CARD_CFG_SEND_DATA struSendData = {0};
    struSendData.dwSize = sizeof(struSendData);
    m_csCardNo = "12";
    strncpy((char*)struSendData.byCardNo, (LPCTSTR)m_csCardNo, ACS_CARD_NO_LEN);

    m_lGetCardCfgHandle = NET_DVR_StartRemoteConfig(lUserID,
        NET_DVR_GET_CARD_CFG_V50, &struCond, sizeof(struCond),
        g_fGetGatewayCardCallback, NULL);

    NET_DVR_SendRemoteConfig(m_lGetCardCfgHandle, ENUM_ACS_SEND_DATA,
        (char*)&struSendData, sizeof(struSendData));

    Sleep(1000);
    if (bGetCardCfgFinish) NET_DVR_StopRemoteConfig(m_lGetCardCfgHandle);

    // ---- APPLY CARD INFORMATION ----
    NET_DVR_CARD_CFG_COND struCond_set = {0};
    struCond_set.dwSize        = sizeof(struCond_set);
    struCond_set.dwCardNum     = 1;
    struCond_set.byCheckCardNo = 1;
    struCond_set.wLocalControlID = 0;  // ana kontrolcü

    m_lSetCardCfgHandle = NET_DVR_StartRemoteConfig(lUserID,
        NET_DVR_SET_CARD_CFG_V50, &struCond_set, sizeof(struCond_set),
        g_fSetGatewayCardCallback, NULL);

    LPNET_DVR_CARD_CFG_V50 lpCardCfg = new NET_DVR_CARD_CFG_V50;
    lpCardCfg->dwSize = sizeof(NET_DVR_CARD_CFG_V50);
    lpCardCfg->dwModifyParamType = 0x000003FF;  // tüm alanlar editlenecek

    m_csCardNo = "12";
    strncpy((char*)lpCardCfg->byCardNo, (LPCTSTR)m_csCardNo, ACS_CARD_NO_LEN);
    lpCardCfg->byCardValid   = 1;
    lpCardCfg->byCardType    = 1;  // normal kart
    lpCardCfg->byLeaderCard  = 0;

    lpCardCfg->byDoorRight[0]   = 1;  // kapı 1: yetkili
    lpCardCfg->byDoorRight[1]   = 1;  // kapı 2: yetkili
    lpCardCfg->byBelongGroup[0] = 1;  // grup 1: üye

    m_csCardPassword = "12345678";
    strncpy((char*)lpCardCfg->byCardPassword, (LPCTSTR)m_csCardPassword,
            CARD_PASSWORD_LEN);

    // Kapı 1 için template 1 ve 2
    lpCardCfg->wCardRightPlan[0][0] = 1;
    lpCardCfg->wCardRightPlan[0][1] = 2;
    // Kapı 2 için template 3 ve 4
    lpCardCfg->wCardRightPlan[1][0] = 3;
    lpCardCfg->wCardRightPlan[1][1] = 4;

    lpCardCfg->dwMaxSwipeTime = 0;  // limit yok
    lpCardCfg->dwSwipeTime    = 0;

    lpCardCfg->struValid.byEnable = 1;
    lpCardCfg->struValid.struBeginTime.wYear  = 2017;
    lpCardCfg->struValid.struBeginTime.byMonth = 1;
    lpCardCfg->struValid.struBeginTime.byDay   = 1;
    lpCardCfg->struValid.struEndTime.wYear  = 2018;
    lpCardCfg->struValid.struEndTime.byMonth = 1;
    lpCardCfg->struValid.struEndTime.byDay   = 1;

    NET_DVR_SendRemoteConfig(m_lSetCardCfgHandle, ENUM_ACS_SEND_DATA,
        (char*)lpCardCfg, sizeof(*lpCardCfg));

    Sleep(1000);
    if (bSetCardCfgFinish) NET_DVR_StopRemoteConfig(m_lSetCardCfgHandle);

    Sleep(5000);
    NET_DVR_Logout(lUserID);
    NET_DVR_Cleanup();
}
```

## 2.2.1 Kart Operasyonları (Card Operation) — ISAPI

> Bu bölüm HCNetSDK yerine **ISAPI text protocol** kullanır. Convex tarafından doğrudan HTTP fetch ile çağrılabilir.

### Yetenek Sorgula
```
GET /ISAPI/AccessControl/CardOperations/capabilities?format=json
→ JSON_CardOperationsCap
```

### M1 Kart İşlemleri

| İşlem | Method | URI | Payload |
|---|---|---|---|
| Encrypt Specific Sections (M1) | PUT | `/ISAPI/AccessControl/CardOperations/sectionEncryption?format=json` | `JSON_SectionEncryption` |
| Verify Section Password (M1) | PUT | `/ISAPI/AccessControl/CardOperations/verification?format=json` | `JSON_Verification` |
| Change Control Block (M1) | PUT | `/ISAPI/AccessControl/CardOperations/controlBlock?format=json` | `JSON_ControlBlock` |
| Read Block Data (M1) | GET | `/ISAPI/AccessControl/CardOperations/dataBlock/<address>?format=json` | → `JSON_DataBlock` |
| Write Block Data (M1) | PUT | `/ISAPI/AccessControl/CardOperations/dataBlock/<address>?format=json` | `JSON_DataBlock` |
| Operate Data Block (M1) | PUT | `/ISAPI/AccessControl/CardOperations/dataBlock/control?format=json` | `JSON_DataBlockCtrl` |

### CPU Kart İşlemleri

| İşlem | Method | URI | Payload |
|---|---|---|---|
| Set Operation Protocol | PUT | `/ISAPI/AccessControl/CardOperations/protocol?format=json` | `JSON_CardProto` |
| Set CPU Card Parameters | PUT | `/ISAPI/AccessControl/CardOperations/cardParam?format=json` | `JSON_CardParam` |
| Reset CPU Card | GET | `/ISAPI/AccessControl/CardOperations/reset?format=json` | → `JSON_CardResetResponse` |
| Pass Through Data Package | PUT | `/ISAPI/AccessControl/CardOperations/dataTrans?format=json` | `JSON_DataTrans` |
| Encrypt CPU Card | PUT | `/ISAPI/AccessControl/CardOperations/encryption?format=json` | `JSON_CardEncryption` |

### Custom Card Information

| İşlem | Method | URI | Payload |
|---|---|---|---|
| Delete Data from Card | PUT | `/ISAPI/AccessControl/CardOperations/clearData?format=json` | `JSON_ClearData` |
| Set Custom Card Info | PUT | `/ISAPI/AccessControl/CardOperations/customData?format=json` | `JSON_CustomData` |
| Search Custom Card Info | POST | `/ISAPI/AccessControl/CardOperations/customData/searchTask?format=json` | `JSON_CustomDataSearchCond` |

## ngsaccess Tarafında Notlar

### Hangi Yaklaşım?
- **Convex action'dan ISAPI HTTP ile** → en pratik, C/C++ DLL gerektirmez. `convex/actions/hikvisionSync.ts` zaten bu yolu kullanıyor.
- HCNetSDK V50 API → kompleks senaryolar (offline distributed controller, persistent connection upload) için.

### Convex Sync Flow Önerisi
ngsaccess'te kart yönetiminin önerilen mimarisi:
```
employees tablosuna kayıt eklendi/güncellendi
  → Convex onUpdate trigger
  → action: syncEmployeeToHikvision
        - cihaz listesini al (employee.accessGroup'a göre)
        - her cihaz için ISAPI PUT/PATCH (yeni: Person + Card)
        - sonuç: success/error → audit log
```

> **Önemli:** Hikvision'da kart bir kişiye bağlı (Person + Card pattern). Eğer cihazda Person olmadan sadece kart kullanılıyorsa, [2.5 Schedule Settings](./2.5-schedule-settings.md) altında **Configure Access Permission Control Schedule** ile template bağlanabilir.

### Önemli Alan Eşlemeleri

| ngsaccess (`employees`) | Hikvision (`NET_DVR_CARD_CFG_V50`) |
|---|---|
| `cardNumber` | `byCardNo[ACS_CARD_NO_LEN]` |
| `name` | (Person object'inde, kart değil) |
| `isActive` | `byCardValid` |
| `validFrom`, `validUntil` | `struValid.struBeginTime`, `struEndTime` |
| `accessGroupIds` | `byBelongGroup[128]` (1=üye) |
| (cihaz seviyesinde) `accessibleDoorIds` | `byDoorRight[256]` (1=yetkili) |
